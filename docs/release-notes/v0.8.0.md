# 玄玑 v0.8.0 — 公开 PyPI 首发

> 北斗第三星·主调度运转。FiveM 服务器主程的 AI 副驾——QBCore / QBox / ESX / OX
> 全家桶开发与服务器运维双轮驱动。
>
> 从 0.8.0 开始，玄玑走出私房菜：`pip install xuanji-fivem` 一句话就能上桌。

## 安装

```bash
# 单独 venv（核心包，~30MB）
python -m venv ~/.xuanji-venv
~/.xuanji-venv/bin/pip install xuanji-fivem

# uv tool（推荐，免冲突独立环境）
uv tool install xuanji-fivem

# pipx 也行
pipx install xuanji-fivem

# 启用 LanceDB 向量后端（可选，多 ~80MB）
pip install 'xuanji-fivem[vector]'
```

> **包名是 `xuanji-fivem`**——`xuanji` 已被别人占了。安装后命令行入口仍叫 `xuanji`，
> 不影响日常用法。

首次跑 `xuanji init` 走交互式向导：填 API Key、导入 FiveM 种子知识、做一次连通性测试。
跑完 `xuanji doctor` 应该全绿。

## 这一版的三件大事

### 1. 真 LanceDB 接入（可选）

之前 0.3 起向量库一直是 **InMemoryVectorStore** ——内存 ndarray，重启即丢。
0.8 把 `LanceDBVectorStore` 真正写成嵌入式列式向量库：

- schema：`id TEXT, vector FixedSizeList<float32, dim>, namespace TEXT, metadata JSON_TEXT`
- upsert 用 `merge_insert("id").when_matched_update_all().when_not_matched_insert_all()`
- L2 距离 → `score = 1.0 / (1.0 + dist)`，越大越相关
- 数据落盘到 `data/vectors/`，跨重启持久化

**核心包不强依赖** ——`lancedb / pyarrow` 在 `[vector]` extra 里。没装就抛 ImportError，
`ServerRuntime` 自动 fallback 到 InMemory，启动不会被卡死。想用就：

```bash
pip install 'xuanji-fivem[vector]'
xuanji knowledge reindex-vectors --backend lancedb
```

> **踩过的坑**：`db.list_tables()` 跨实例不立刻看见新建的表，会触发
> `Table 't' already exists`。`_ensure_table` 改成 try `open_table` → 失败再
> `create_table` 才稳。

### 2. Hooks `--explain` dry-run 模式

写 hook 最怕的不是 hook 跑了，是 hook **没跑**——matcher 写错了你完全不知道。
0.8 加 `xuanji hook explain` 干跑分析，**不启动子进程**，纯静态告诉你：

- 这个事件下注册了哪些 hook
- 当前 tool / prompt 会命中哪些
- 没命中的 hook，原因是什么（matcher 不匹配 / 子串不在 prompt 里）
- 这个事件下，hook 拒绝是否真的有效（**只有 PreToolUse 的 `can_deny=True`**）

```bash
xuanji hook explain --event PreToolUse --tool run_shell
xuanji hook test --event PreToolUse --tool run_shell --payload-json '{"args":{"cmd":"ls"}}'
```

`HookExplanation` 也对外暴露给程序化测试用——集成测试不执行 hook 也能断言注册。

### 3. 内置示范 skill / hook，开箱即用

新模块 `xuanji.resources` 内置了 6 个开箱样例，`install-samples` 一键拷到用户目录：

**3 个 skill**（FiveM 实战）：

| skill | 干什么 |
|---|---|
| `qbox-add-useable-item` | QBox `CreateUseableItem` + ox_inventory 注册可使用物品 |
| `ox-lib-callback` | `lib.callback.register` / `lib.callback.await` client/server 双侧 |
| `fxmanifest-audit` | fxmanifest.lua review checklist（mode: review / role_hint: 司鉴）|

**3 个 hook**（运维守门）：

| hook | 干什么 |
|---|---|
| `PreToolUse.yaml` | `rm -rf /` 黑名单 + `.env` 写入警告（python -c 内嵌脚本，跨平台）|
| `PostToolUse.yaml` | run_shell 命令日志到 stderr |
| `UserPromptSubmit.yaml` | 「部署 / 生产 / QBox」substring 提示 |

```bash
xuanji skill-file install-samples           # 拷 3 个 skill
xuanji hook install-samples                 # 拷 3 个 hook
xuanji skill-file install-samples --force   # 已存在的话强制覆盖
```

skill 和 hook 都跟 **Claude Code / Codex 互通** ——文件可双向迁移。玄玑特定字段
放在 `metadata.xuanji.*` 子树里，对方看不见也不会出错。

## 升级

从 0.7.x 升上来：

```bash
# 如果你之前在用 GitHub Packages 私有源
pip install -U xuanji-fivem  # 直接换公开 PyPI

# 想体验 LanceDB
pip install -U 'xuanji-fivem[vector]'
xuanji knowledge reindex-vectors --backend lancedb
```

API 没有 breaking change。`__version__` 自动回正，`xuanji version` 应当显示 `0.8.0`。
